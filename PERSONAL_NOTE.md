
This project started as mine and a good friend's submission to the CSULB AI x Data Datathon — the first competition either of us had ever entered. Building it start to finish in just over 24 hours was genuinely rewarding, deadline chaos and all.
We picked the Unsupervised Learning track, which meant learning a lot of these clustering concepts as we went. Use of AI was encouraged in the competition, but it was emphasized that how well you could prompt and direct it mattered just as much as the output — so a good chunk of what we learned wasn't just K-Means and PCA, it was how to actually use AI to build a working custom UI under time pressure, and what decent prompt engineering looks like in practice.

After the datathon wrapped, I came back to the project on my own and cleaned it up — added some things, cut others, fixed what I found that didn't hold up under a closer look. Section 7 of the model report had been left blank at submission ("intentionally left blank," it said) even though the reasoning behind it already existed in one of our notebooks — it just never made it into the writeup in time. I also traced down a labeling bug where a field was still called "Zip Code (uncertain)" when both the app and our own analysis clearly pointed to it being credit balance.

None of that changes the model but I really just wanted this to be semi-presentable. This is my first official GitHub showcase project, still rough in places, but happy with how it turned out. More fun projects to come.
— Prithvi
